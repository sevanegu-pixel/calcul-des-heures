# Calcul des heures

Application web pour noter ses heures de cours, ses entraînements libres et ses points (bonus progressif).

- Ouvrir : https://sevanegu-pixel.github.io/calcul-des-heures/
- Connexion par identifiant + code PIN à 6 chiffres, valable 6 mois par appareil.
- Les données sont stockées dans un Google Sheets privé ; ce dépôt ne contient que l'interface.
- Sur téléphone : menu du navigateur → « Ajouter à l'écran d'accueil ».
